Coin of the Realm Texture
==========================

This directory should contain a texture file named: coin_of_the_realm.png

Requirements:
- Size: 16x16 pixels (standard Minecraft item texture size)
- Format: PNG with transparency support
- Content: A small, round, gold coin design

The texture will be used when players have the resource pack installed.
Players without the resource pack will see a gold nugget as a fallback.

To create the texture:
1. Design a 16x16 pixel gold coin texture
2. Save it as coin_of_the_realm.png in this directory
3. The texture should be circular/round to represent a coin
4. Use gold/yellow colors to match the "Coin of the Realm" theme

Example design ideas:
- Circular coin with a border
- Simple gold circle with a symbol or text in the center
- Stylized coin with decorative elements
